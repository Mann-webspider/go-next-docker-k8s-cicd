# Kubernetes & CI/CD Pipeline Showcase (`k8s-devops-pipeline`)

A production-ready DevOps implementation featuring multi-stage Docker containerization, 
automated GitHub Actions CI/CD workflows, and Kubernetes orchestration (Ingress, ConfigMaps, 
HPA) hosting a minimal Go & Next.js event-tracking workload.

## 🛠️ DevOps Practices & Tech Stack
* **Containerization:** Docker (Multi-stage builds, rootless execution)
* **CI/CD:** GitHub Actions (Automated lint, test, build, image push to GHCR)
* **Orchestration:** Kubernetes (Deployments, Services, Nginx Ingress, Secrets, HPA)
* **Application Workload:** Go (REST API) + Next.js (Frontend)
